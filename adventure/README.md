# Adventure Game

A JavaScript-based adventure game featuring quests, characters, and an immersive world.

## Features

- Dynamic character system
- Quest-based gameplay
- Interactive world exploration
- Core game mechanics

## Files

- `main.js` - Entry point and game initialization
- `core.js` - Core game engine and logic
- `characters.js` - Character definitions and behaviors
- `quests.js` - Quest system and objectives
- `world.js` - World map and environment

## How to Run

1. Open `index.html` in a web browser
2. Or use a local server:
   ```bash
   npx serve .
   ```

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
